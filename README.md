# The-Archives
A Vintage Dark Academia Library for Google Docs

Primary Platform : A website
Secondary Platform : Chrome Extension

Core user journey
1. Open The Archive website.
2. See the antique entrance.
3. Click the door.
4. Enter the library.
5. Browse books arranged on shelves.
6. Search, filter or select a book.
7. Open the original Google Doc.

* Phase 1 : Frontend/ Pages Designing with Figma
